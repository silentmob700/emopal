Deploying the **EmoPal** project involves setting up three database services (MySQL, MongoDB, Redis), running the Node.js backend, and serving the React frontend.

Here is the complete deployment guide.

### 1. Architecture Overview
*   **Frontend**: React (Vite) - served via Nginx or static server.
*   **Backend**: Node.js (Express + TypeScript) - runs on port 5000.
*   **Databases**:
    *   **MySQL**: User data, structured relationships (Port 3306).
    *   **MongoDB**: Chat history, unstructured data (Port 27017).
    *   **Redis**: Session management, online status (Port 6379).

---

### 2. Prerequisites
Ensure the server (Linux recommended, e.g., Ubuntu) has the following installed:
*   **Node.js** (v18 or higher) & `npm`
*   **MySQL** (v8.0+)
*   **MongoDB** (v5.0+)
*   **Redis**
*   **Nginx** (Web Server & Reverse Proxy)
*   **PM2** (Process Manager for Node.js) -> `npm install -g pm2`

---

### 3. Database Setup

#### MySQL
1.  Log in to MySQL: `mysql -u root -p`
2.  Create the database:
    ```sql
    CREATE DATABASE Emo_pal CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
    ```
3.  Import the initialization script:
    ```bash
    mysql -u root -p Emo_pal < "backend/src/database/quick-deploy.sql"
    ```

#### MongoDB & Redis
Ensure these services are running. Default configurations usually work without changes for local/single-server deployment.
*   **MongoDB URL**: `mongodb://localhost:27017/emopal`
*   **Redis URL**: `redis://localhost:6379`

---

### 4. Backend Deployment

1.  **Navigate to backend directory**:
    ```bash
    cd backend
    ```

2.  **Install Dependencies**:
    ```bash
    npm install
    ```

3.  **Configure Environment**:
    Create a `.env` file (copy from `.env` example) and update production values:
    ```env
    BACKEND_PORT=5000
    NODE_ENV=production
    FRONTEND_URL=http://your-domain.com  # Or http://localhost if local
    
    # Database
    DB_HOST=localhost
    DB_USER=root
    DB_PASSWORD=your_mysql_password
    DB_DATABASE=Emo_pal
    
    # MongoDB & Redis
    MONGODB_URI=mongodb://localhost:27017/emopal
    REDIS_URL=redis://localhost:6379
    
    # AI Keys (Ensure these are set)
    GEMINI_API_KEY=your_key
    COZE_TOKEN=your_token
    ```

4.  **Build the Project**:
    ```bash
    npm run build
    ```

5.  **Start with PM2**:
    ```bash
    pm2 start dist/server.js --name "emopal-backend"
    ```

---

### 5. Frontend Deployment

1.  **Navigate to frontend directory**:
    ```bash
    cd frontend
    ```

2.  **Install Dependencies**:
    ```bash
    npm install
    ```

3.  **Configure Environment**:
    Create `.env.production`:
    ```env

    VITE_API_URL=/api
    ```

4.  **Build the Project**:
    ```bash
    npm run build
    ```
    This will generate a `dist` folder containing the static files.

### 6. Nginx Configuration (The Glue)

Nginx will serve the frontend files and forward API requests to the backend.

1.  **Create Nginx Config**: `/etc/nginx/sites-available/emopal`
    ```nginx
    server {
        listen 80;
        server_name your-domain.com;  # Or localhost

        # Serve Frontend Static Files
        location / {
            root /path/to/your/project/frontend/dist;
            index index.html;
            try_files $uri $uri/ /index.html;
        }

        # Proxy API Requests to Backend
        location /api {
            proxy_pass http://localhost:5000;
            proxy_http_version 1.1;
            proxy_set_header Upgrade $http_upgrade;
            proxy_set_header Connection 'upgrade';
            proxy_set_header Host $host;
            proxy_cache_bypass $http_upgrade;
        }

        # Proxy WebSocket (Socket.io)
        location /socket.io/ {
            proxy_pass http://localhost:5000;
            proxy_http_version 1.1;
            proxy_set_header Upgrade $http_upgrade;
            proxy_set_header Connection "upgrade";
            proxy_set_header Host $host;
        }

        # Proxy Uploaded Images
        location /img {
            proxy_pass http://localhost:5000/img;
        }
    }
    ```

2.  **Enable Site & Restart Nginx**:
    ```bash
    ln -s /etc/nginx/sites-available/emopal /etc/nginx/sites-enabled/
    nginx -t
    systemctl restart nginx
    ```
